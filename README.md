# SkyPulse Weather App

A responsive, real-time weather dashboard application built to deliver precise forecasts based on user location or manual search.

---

## 🛠️ Tech Stack
* **Framework:** React / Next.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Data Sources:** Open-Meteo REST API, Native Geolocation Web API
* **Deployment:** Vercel

---

## Key Features
* **Live Location Forecasts:** Automatically detects user coordinates via the browser Geolocation API to fetch local weather data.
* **REST API Integration:** Fetches real-time temperature, wind speed, humidity, and 7-day weather predictions from Open-Meteo.
* **Search Functionality:** Allows users to query global city locations with instant data updates.
* **Responsive UI:** Fully optimized layout for seamless display across mobile, tablet, and desktop screens.
